# Org

The org tree from the org tool: collapsible, the chain of command to the top for anyone, links, and org changes from the log.

Built into the starter HQ (`hanialshater/system3-meta`, `hq/index.html`): every company has it, shown when it has something to show. It reads only org, events, dashboard, through the company's tools (STARTER.md §3).
